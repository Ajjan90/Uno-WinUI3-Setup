# Setting up Uno Platform project to create a Windows WinUI3 App

<p> This repository will help programmers set up the your <b>Uno Platform</b> project to create Windows 11 apps using the Fluent Design </p>


## What is WinUI3

<p> <img src="/Assets/WinUI.webp"> WinUI3 is the native UI framework for Windows desktop apps, it brings the Fluent design system into your application using XAML to deisgn the UI interface while using <b>C#</b> or <b>C++</b> for th backend of the desktop application. </p>

<p>More about WinUI3 on <a href="https://learn.microsoft.com/en-us/windows/apps/winui/winui3/" >Microsoft Learn - WinUI 3</a> </p>

## What is Uno Platform

<p> <img src="/Assets/Uno-Logo.png"> The Uno Platform is an open-source, cross-platform .NET and WinUI/XAML framework that allows developers to write single-codebase applications in C# and XAML and deploy them across mobile, desktop, web, and embedded systems </p>

<p>More about Uno Platform on <a href="https://platform.uno/docs/articles/what-is-uno.html" >Uno Platform - About</a> </p>

## Installation
Before you can create a project, you will need to download the WinUI framework and the Uno Platform first.

<p> You will need to download <a href="https://visualstudio.microsoft.com/downloads/">Visual Studio 2026 Community</a> </p>

To download WinUi3 on Visual Studio 2026, read the Microsoft Learn website.
<a href="https://learn.microsoft.com/en-us/windows/apps/get-started/start-here?tabs=visual-studio"> More on Microsoft Learn - Build your first WinUI app </a>

To download Uno Platform go to the <a href="https://platform.uno/studio-download/">Uno Platform - downloads</a>
